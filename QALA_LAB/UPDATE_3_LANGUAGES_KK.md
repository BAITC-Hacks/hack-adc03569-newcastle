# QALA LAB 1.1 — үш тілдегі сайт

Сайт тілдері: **Қазақша / Русский / English**. Жоғарғы панельдегі **ҚАЗ / РУС / ENG** батырмаларын қолданыңыз.

## Ескі нұсқаның орнына іске қосу

1. Ескі сервер жұмыс істеп тұрса, оның терминалында `Ctrl+C` басыңыз.
2. Жаңа ZIP-ті бөлек папкаға толық шығарыңыз. Архивтің ішінен іске қоспаңыз.
3. VS Code-та жаңа `QALA_LAB` папкасын ашыңыз. Оның ішінде `server.py`, `app`, `web` бірге тұруы керек.
4. **Terminal → New Terminal** ашып, орындаңыз:

```powershell
py -3 server.py --open
```

`py` танылмаса:

```powershell
python server.py --open
```

Мекенжай:

```text
http://127.0.0.1:8000
```

**8080 емес, 8000.** Терминалды ашық қалдырыңыз. Ескі интерфейс көрінсе, `Ctrl+F5` басып жаңартыңыз және серверді жаңа папкадан қосқаныңызды тексеріңіз.

Бұрын `.env` арқылы өз API кілтіңізді қосқан болсаңыз, сол `.env` файлын жаңа `QALA_LAB` папкасына өз компьютеріңізде көшіріңіз. Жаңа архивте жеке кілт жоқ. Кілтті чатқа немесе GitHub-қа жібермеңіз.

## Не жаңарды?

- Ағылшын тілі: барлық бөлімдер, шаралар, аудандар, көрсеткіштер, қате хабарламалары, демо нұсқаулық және басып шығарылатын есеп.
- Тіл таңдау `localStorage` арқылы сақталады. Тілді ауыстыру таңдалған шараларды өзгертпейді.
- Дайын түсіндірме үш тілге бірден ауысады: сервер әр дәлелдің үш аудармасын жібереді. Тілді ауыстырудың өзі қосымша AI сұрауын жібермейді.
- Мобильді нұсқада үш тіл батырмасы қолжетімді; тар экранда карточкалар бір бағанға өтеді.
- Бастапқы деректердің сандары, есептеу формуласы мен шаралардың әсерлері өзгертілмеді.

JSON/CSV техникалық өріс атаулары тұрақты күйде қалды. Пайдаланушы өзі енгізген сценарий атауы мен еркін мәтіні автоматты аударылмайды. Дайын сұрақ батырмалары аударылады.

## Тексерулер

```powershell
py -3 -m unittest discover -s tests -v
```

**125 unittest тесті өтті**, оның 20-сы — үш тілге арналған жаңа тексерулер. Бұған нақты жергілікті HTTP серверімен ағылшын тіліндегі жауап пен қате хабарламаларын тексеру кіреді.

Қосымша **57 интерфейс тексеруі** Chromium-дағы желісіз жергілікті рендерерде өтті. Оған өзіміздің HTML/CSS/JS және есептеу модулінің деректері тікелей берілді; HTTP пен localStorage орнына тесттік алмастырғыш қолданылды. Сондықтан бұл толық желілік браузер end-to-end тесті немесе дискіге нақты сақтау сынағы емес. HTTP бөлігі бөлек unittest арқылы тексерілді. 320, 390, 1024 және 1440 px ендері қаралды.

Тірі LLM сұрауы орындалмады: ағылшын тілі үшін жергілікті түсіндірме, mock LLM сұрауы және қате кезіндегі fallback тексерілді. Windows-та нақты іске қосу осы Linux ортасында тексерілген жоқ.

Есеп: `docs/TRILINGUAL_TEST_REPORT.md`. Тек сайт жаңартылды: бұрын берілген қазақша презентация, PDF құжаттар және ескі скриншоттар 1.0 нұсқасының материалдары ретінде сақталды. Жаңа суреттер `docs/i18n/` ішінде.

## Паспорт идентификаторы туралы

Тек аудармалар қосылса да, JSON датасетінің және код файлының хэші өзгереді. Сондықтан 1.0 нұсқасында сақталған сценарийді импорттағанда жаңа паспорт ID жасалуы қалыпты. Сценарийдің сандық нәтижесі өзгермеуі керек. `examples/reference_output.json` 1.1 нұсқасымен қайта жасалды; бұрынғы дайын PDF-паспорт — 1.0 нұсқасының мысалы.
