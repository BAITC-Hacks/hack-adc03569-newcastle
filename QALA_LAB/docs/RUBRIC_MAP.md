# Бағалау талаптарына сәйкестік картасы

Негіз: `sources/brief.pdf`, 3-беттегі бағалау кестесі. Төменде жоба материалдары көрсетілген; бұл өзімізге қойылған баға немесе нәтиже кепілі емес.

| Түпнұсқа критерий | Балл | Берілген дәлел | Қорғауда көрсету |
|---|---:|---|---|
| Тапсырмаға сәйкестік және жұмыс істеуі | 25 | Бюджет 100, дәл 5 шара, 14 шара/5 аудан, валидация, берілген формула | Демо, шараны алып тастау, сервердің қате себебі |
| Техникалық іске асыру | 25 | Decimal engine, серверлік валидация, AI evidence IDs, 50-cell ledger, API, тесттер | S1 есеп ізі, AI режимі, тест нәтижесі |
| README және қайта орындау | 25 | Бір командамен іске қосу, дайын мысал, түпнұсқа құжаттар, 105 тест, JSON паспорт | README, `unittest`, импорт/экспорт |
| Құндылық және қолданылуы | 15 | Шешім әсерін түсіндіру, A/B айырмасы, шектеулердің ашық берілуі | Қолданушы сценарийі; нақты пайдаланушы зерттеуі жасалмағанын айту |
| Даму әлеуеті және өзіндік тәсіл | 10 | Дәлелге байланған түсіндірме, есеп паспорты, бөлек сезімталдық тәжірибесі | M7 +1 тоқсан; ресми сценарий ID өзгермейді |

## Must-have тексеру

| Талап | Іске асырылуы / ескерту |
|---|---|
| Барлығына бірдей бастапқы бюджет | Бір серверлік dataset; budget=100 |
| Бес бағыттағы шешімдер | Бес категория, егжей-тегжейлі датасеттегі max2/category ережесі |
| Бюджеттен асырмау | Клиент енгізуі серверде тексеріледі; invalid set есептелмейді |
| AI талдау | Responses API evidence selection іске асырылған; нақты кілтпен байланыс тексерілуі керек |
| Astana Quality of Life Score | Ұйымдастырушының формуласы, Decimal және эталон тест |
| Әсерлер, тәуекел/компромисс түсіндірмесі | Сандық әсерлер, лаг, синергия, M11 екі жақтылығы, дерек шектеулері |

## Опционалды мүмкіндіктер

Бір браузерде сақталған екі сценарийдің айырмасын қарау бар; командалар рейтингі немесе көп аккаунттық сервис жоқ. Аудандық визуализация, ұяшық ізі, JSON/CSV және басып шығарылатын есеп бар. Кешігу тәжірибесі бөлек қосылған; оны ұйымдастырушының ресми оқиға деректері ретінде көрсетпеу керек. Қорғауға арналған өңделетін презентация берілген, бірақ қолданба әр сценарийге автоматты PPTX жасамайды. Қолданба сценарийге арналған PDF-паспортты браузердің басып шығаруымен жасайды.

## Шынайы жеткізу шегі

Локалды прототип дайын. Тірі LLM тексеруі, команданың ноутбугіндегі толық демонстрация және жарыс платформасына жариялау — тапсыру алдындағы қалған әрекеттер. Репозиторийге автоматты жариялау, ашық hosting, Windows/CI/Docker орындалды деп көрсетілмейді.
