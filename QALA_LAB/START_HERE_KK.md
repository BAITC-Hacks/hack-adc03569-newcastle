# Алдымен осы файлды оқыңыз

**1.1 нұсқасы — үш тіл: ҚАЗ / РУС / ENG.** Жаңарту нұсқаулығы: [UPDATE_3_LANGUAGES_KK.md](UPDATE_3_LANGUAGES_KK.md).

## 1. Сайтты іске қосу

ZIP архивін толық шығарыңыз. Архивтің ішінен бірден іске қоспаңыз.
`QALA_LAB` папкасында `server.py`, `app` және `web` бірге тұруы керек.

Windows-та `START_WINDOWS.bat` файлын екі рет басыңыз. Python 3.11 немесе одан жаңа нұсқа керек. Сайт браузерде ашылады. Қара терминал терезесін жаппаңыз: ол — сервер.

VS Code арқылы:

1. **File → Open Folder** арқылы `QALA_LAB` папкасын ашыңыз.
2. **Terminal → New Terminal** ашыңыз.
3. Мына команданы орындаңыз:

```powershell
py -3 server.py --open
```

`py` табылмаса, бірақ Python орнатылған болса:

```powershell
python server.py --open
```

Браузер мекенжайы:

```text
http://127.0.0.1:8000
```

Қосымша пакет орнату қажет емес. `npm install` да, `pip install -r requirements.txt` та қажет емес.
`index.html` файлын жеке ашпаңыз: ол Python серверінің API-сымен жұмыс істейді.
Тоқтату: терминалда `Ctrl+C`.

## 2. Алғашқы көрсетілім

Жоғарыдағы **Демо** батырмасын басыңыз. Ұйымдастырушының мысалы жүктеледі және 5 қадамдық қорғау нұсқаулығы ашылады. Ол «ең жақсы сценарий» емес, тек тексеру мысалы.

**Қалаға шолу** → Нұра → **S1** көрсеткіші: бастапқы 38-ге `16 × (8−3)/8 = 10` қосылғанын көресіз. Бұл — түпнұсқа датасеттің §2–3 бөлімдеріне сүйенген арифметикалық мысал.

**Есеп ізі** бөлімінде толық 50 ұяшықтың журналын және JSON-паспортты ашыңыз.
**AI түсіндірме** → **Түсіндір**. Жоғарыдағы режим белгісін міндетті түрде оқыңыз.

## 3. Нақты LLM-ді қосу

Кілтсіз есептеу, барлық экрандар, салыстыру және жергілікті шаблон түсіндірмесі жұмыс істейді. Бірақ жергілікті шаблонды «жанды AI» деп таныстырмаңыз.

`.env.example` файлының көшірмесін `.env` деп атаңыз. Мысал:

```dotenv
OPENAI_API_KEY=өзіңіздің_кілтін_осында_қойыңыз
OPENAI_MODEL=gpt-4.1-mini
```

Кілтті сақтап, серверді тоқтатып қайта іске қосыңыз. Интернет қосулы болуы керек. **AI түсіндірме** → **Түсіндір** батырмасын басыңыз. Сәтті сұраудан кейін `LLM · VERIFIED IDs` белгісі шығады. API кілтінің жай ғана табылуы — байланыстың сәтті болғанының дәлелі емес.

Кілт `.env` ішінде ғана болсын. Оны `app.js` файлына, скриншотқа, ZIP-ке немесе GitHub-қа қоспаңыз. `.gitignore` оны әдейі елемейді.

Жоба дайындалған ортада нақты API кілті қолданылған жоқ: тірі LLM жауабы тексерілмеді. Интеграцияның сұрау пішіні мен қатеден қалпына келу жолдары mock-тесттермен тексерілді.

## 4. Қорғауға дайындық

```powershell
py -3 -m unittest discover -s tests -v
```

Соңында `OK` шығуы керек. 1.1 жинағында 125 тест әдісі бар; бір тест қосымша 1000 жарамды кездейсоқ сценарийді тәуелсіз есептеумен салыстырады, ал басқа тест бір жиынтықтың 120 ретін тексереді.

`docs/DEMO_KK.md` — 3 минуттық сөйлеу мәтіні мен қай батырманы басу керегі.
`docs/DEFENSE_KK.md` — қазылардың сұрақтарына дайын жауаптар.
`docs/QALA_LAB_Pitch_KK.pptx` — өңдеуге болатын презентация.
`docs/QALA_LAB_Pitch_KK.pdf` — презентацияның PDF көшірмесі.

## 5. Жиі кездесетін қателер

| Белгі | Не тексеру керек |
|---|---|
| `python` / `py` табылмайды | Python орнатылғанын `py -3 --version` немесе `python --version` арқылы тексеріңіз. |
| `can't open file server.py` | Терминал `QALA_LAB` папкасында ашылуы керек. |
| `Address already in use` | Бұрынғы сервер терезесін жабыңыз немесе `py -3 server.py --port 8001 --open` орындаңыз. |
| Сайт ашылды, бірақ дерек жоқ | `index.html` емес, `http://127.0.0.1:8000` мекенжайын ашқаныңызды тексеріңіз. |
| `ЖЕРГІЛІКТІ ШАБЛОН` шығады | Бұл LLM емес. `.env`, интернет және API жауабын тексеріңіз. Себеп коды интерфейсте көрсетіледі. |
| `provider_http_401` | API сервері кілтті қабылдамады; кілтті тексеріңіз. |
| `provider_http_429` | API сұрауды шектеді; нақты аккаунттағы лимитті тексеріңіз. |
| 5-ші шара қабылданбайды | Бюджет, бір бағыттан 2-ден аспау және үйлесім шектеулерін тексеріңіз. |

Бұл жинақ — локалды прототип. Ашық интернетке өндірістік сервис ретінде жарияланған жоқ. Docker және Windows іске қосу файлдары берілген, бірақ әзірлеу ортасындағы нақты орындау Linux/Python 3.13.5 арқылы жасалды.
