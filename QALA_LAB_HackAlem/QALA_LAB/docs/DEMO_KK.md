# Қорғау: 3 минуттық демо

## Дайындық

Сайтты іске қосыңыз, экранды үлкейтіңіз, қажетсіз терезелерді жабыңыз. `python -m unittest discover -s tests -v` командасын алдын ала орындаңыз. Презентацияның PPTX/PDF көшірмесін ашып қойыңыз. Үлгі паспорт `docs/Example_Passport_KK.pdf` ішінде бар.

LLM кілті қосылған болса, бір сұрауды алдын ала орындап, **жауаптың** `LLM · VERIFIED IDs` режимін тексеріңіз. Тек кілт конфигурациясының болуы сәтті API байланысын дәлелдемейді. Offline режимін AI деп атамаңыз.

## 0:00–0:25 — мәселе және өнім

**Экран:** «Қалаға шолу», Демо батырмасы.

> Сәлеметсіздер ме! Біздің жоба — QALA LAB. Ұраны: «5 шешім. Әр санға дәлел». Қалаға арналған сценарийде бір ғана қорытынды сан жеткіліксіз. Пайдаланушы сол санның қайдан шыққанын, қандай көрсеткіш өзгергенін және модель нені білмейтінін көре алуы керек. Біз осы тексерілетін жолды жасадық.

## 0:25–0:55 — нақты жұмыс істейтін сценарий

**Әрекет:** «Демо» → нұсқаулықты жабу. «Шешімдер» бөліміне өту.

> Мұнда ұйымдастырушы берген синтетикалық деректер қолданылады: 100 шартты бірлік, 14 шара, 5 аудан. Пайдаланушы дәл 5 шара таңдайды. Бюджет, аудан, қайталану, бір бағыттан екі шарадан аспау және үйлеспейтін жұптар серверде тексеріледі. Экрандағы жиынтық — ұйымдастырушының тексеру мысалы, біздің «ең дұрыс жоспар» деген ұсынысымыз емес.

**Қысқа көрсету:** M5-ті алып тастаңыз. «Сценарий әлі жоқ» белгісін көрсетіңіз. «Демо» арқылы бастапқы мысалға оралып, нұсқаулықты жабыңыз.

## 0:55–1:30 — басты ерекшелік: есептің ізі

**Әрекет:** «Есеп ізі» → Нұра, S1 ұяшығы.

> Енді кез келген санды ашамыз. Мектеп шарасының толық әсері — 16, лагы — үш тоқсан. Код `16 × (8−3)/8 = 10` деп есептейді. Бастапқы мән, әр әсер, синергия, шектеу және соңғы мән осында сақталған. Бұл тек бір мысал: журнал барлық 50 ұяшық үшін жасалады. JSON импортында дайын санға сенбейміз — бәрін қайта есептейміз.

## 1:30–2:00 — AI-дың нақты міндеті

**Әрекет:** ұяшықты жабу → «AI түсіндірме» → «Лаг нәтижеге қалай әсер етті?» → «Түсіндір».

**API жұмыс істеп тұрса:**

> LLM сандарды есептемейді. Ол дайын есептен сұраққа қатысты дәлел ID-ларын таңдайды. Сервер ID-ларды тексеріп, өзіндегі фактілермен түсіндірме жасайды. Белгісіз ID немесе қосымша еркін мәтін қабылданбайды. Бұл дерекке байлануды береді, бірақ түсіндірменің толықтығын адам тексереді.

**Кілтсіз немесе API қатесі болса:**

> Қазір интернетке тәуелсіз шаблон режимі көрсетіліп тұр. Ол LLM емес, белгісі экранда ашық жазылған. Нақты Responses API интеграциясы кодта бар; кілт қосылғанда дәлел ID таңдауын LLM орындайды. Есептеу бұл қызметке тәуелді емес.

## 2:00–2:30 — жорамал ресми нәтижені өзгертпейді

**Әрекет:** «Мерзім зертханасы» → M7 → +1 тоқсан → «Өзгерістерді есептеу».

> Бұл — команда қосқан бөлек тәжірибе. Бір шара кешіксе, тек көрсеткіштің өзгерісін қараймыз. Ресми сценарий мен паспорт сол күйінде қалады. Біз датасетте жоқ ықтималдықты немесе нақты қала болжамын ойдан қоспаймыз.

## 2:30–3:00 — тексеру және қорытынды

**Әрекет:** «Қалаға шолу» → паспорт/принтер белгісін көрсету. Қажет болса терминалдағы тест нәтижесін ашу.

> Жобаға 105 автоматты тест қосылған. Оның ішінде 1000 жарамды сценарий тәуелсіз есептеумен салыстырылады, бір жиынтықтың 120 түрлі реті бірдей нәтиже береді. Жобаны бір Python командасымен іске қосуға болады. QALA LAB пайдаланушының орнына таңдау жасамайды. Біз нәтижеге соқыр сенуді емес, оның қалай алынғанын тексеруді ұсынамыз.

## 30 секундтық резерв мәтін

> QALA LAB — бес басқару шешімінің модельдегі әсерін ашық көрсететін симулятор. Сандарды Decimal модулі есептейді, ал AI тек тексерілген дәлелдерді таңдайды. Әр көрсеткіштің есеп ізі, салыстыру, бөлек мерзім тәжірибесі және қайта есептелетін паспорт бар. Бұл — нақты Астанаға болжам емес, ұйымдастырушының синтетикалық деректерімен жұмыс істейтін тексерілетін прототип.

## Техникалық резерв

Интернет болмаса: есептеуді және ашық белгіленген offline түсіндірмені көрсетіңіз. Браузердегі жоба іске қосылмаса: алдын ала дайындалған PPTX/PDF пен паспортты көрсетіп, оны тірі демо деп атамаңыз. API қате берсе, себеп кодын жасырмаңыз. Толық жоба ZIP-і мен команданың ноутбугіндегі жұмыс көшірмесі бөлек сақталсын.

Уақыттар — жаттығуға арналған үлестірім; сөйлеу жылдамдығына қарай мәтінді қысқартыңыз.
